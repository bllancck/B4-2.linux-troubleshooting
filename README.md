어떤 과제인가?
제공된 프로그램을 실행해서 장애를 관찰하고 → 증거를 수집하고 → 원인을 설명하고 → 설정을 바꿔 결과를 비교한 뒤 → 보고서로 남기는 과제

제약사항
1. 제공된 프로그램을 실행할 수 있는 linux 환경 필요
2. root로 실행 금지. 일반 사용자 계정 사용
3. 환경 변수 설정
로그 디렉토리는 쓰기 권한이 있어야 하고, `0.0.0.0:15034` 포트 사용
4. 바이너리 디컴파일 및 리버스 엔지니어링 시도 금지
프로그램 내부 코드를 뜯어보지 않고, 밖에서 로그와 시스템 상태를 관찰해서 원인을 추론해야 함.
