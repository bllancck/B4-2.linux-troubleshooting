# 과제 개념 정리

과제를 진행하며 새로 등장하는 낯선 기술 용어와 개념을 정리하는 문서입니다.

<a id="heap"></a>

## Heap

Heap은 프로그램이 실행 중 필요한 작업 데이터를 동적으로 할당해 저장하는 메모리 영역입니다.

이 프로젝트에서는 `MemoryWorker`가 데이터를 계속 추가하면서 Heap 사용량을 늘립니다. 설정한 `MEMORY_LIMIT`을 넘으면 애플리케이션의 `MemoryGuard`가 제한 초과를 감지합니다.

<a id="rss"></a>

## RSS (Resident Set Size)

RSS는 Linux가 실제 RAM에 올려둔 프로세스 전체 메모리 사용량입니다.

Heap뿐 아니라 Stack, 프로그램 코드, 공유 라이브러리, 스레드 관련 메모리 등을 포함합니다. 따라서 Heap은 RSS의 일부이고, 두 값은 정확히 같지 않을 수 있습니다.

```text
RSS (프로세스 전체 메모리)
├─ Heap
├─ Stack
├─ 코드·라이브러리
└─ 스레드 및 기타 메모리
```

이 프로젝트에서는 애플리케이션 로그의 Heap 값과 `ps` 또는 `top`으로 확인한 RSS를 함께 비교합니다.
